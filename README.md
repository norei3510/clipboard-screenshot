# Clipboard Screenshot

Windowsで画面の範囲を選び、画像ファイルを保存せずにクリップボードへコピーするツールです。ChatGPTなどにそのまま貼り付けられます。

## 使い方

1. `スクショ起動.vbs` をダブルクリックします。
2. 画面上でコピーしたい範囲をドラッグします。キャンセルする場合は `Esc` を押します。
3. ChatGPTなどの入力欄で `Ctrl + V` を押して貼り付けます。

`スクショ起動.vbs` と `ClipboardCapture.ps1` は同じフォルダーに置いてください。起動から範囲選択が表示されるまで、少し待つ場合があります。

## Copilotキーに割り当てる

Windows、Git Bash、AutoHotkey v2が必要です。この設定はCopilotキーが `Windows + Shift + F23` を送るキーボードに対応しています。別のキー入力を送る機種では `copilot-hotkey.ahk` のキー設定を変更してください。

Git Bashでこのフォルダーを開き、次を実行します。

```bash
bash setup-copilot-key.sh
```

以後はCopilotキーを押すと範囲選択が始まります。セットアップによってWindowsのスタートアップにショートカットが作成され、ログイン時に自動で有効になります。

別のアプリが同じキーを使用している場合は、そちらの設定を手動で解除してください。フォルダーを移動した場合は、移動先でセットアップを再実行してください。

解除するときは、スタートアップフォルダーの `ClipboardScreenshot.lnk` を削除し、通知領域のAutoHotkeyを終了します。

## 別のキーに割り当てる

1. `スクショ起動.vbs` のショートカットを作成し、デスクトップに移動します。
2. ショートカットを右クリックし、「プロパティ」を開きます。
3. 「ショートカット キー」欄をクリックして使いたいキーを押し、「OK」を押します。通常は `Ctrl + Alt + 選んだキー` になります。

ほかのアプリのショートカットと重ならない組み合わせを選んでください。

## 注意

画像ファイルは作成しませんが、Windowsのクリップボード履歴や同期を有効にしている場合は、画像が履歴や同期先に残ることがあります。
