# Clipboard Screenshot

Windowsで画面の範囲を選び、画像ファイルを保存せずにクリップボードへコピーするツールです。ChatGPTなどにそのまま貼り付けられます。

## 使い方

1. `スクショ起動.vbs` をダブルクリックします。
2. 画面上でコピーしたい範囲をドラッグします。キャンセルする場合は `Esc` を押します。
3. ChatGPTなどの入力欄で `Ctrl + V` を押して貼り付けます。

リポジトリ内のファイルを同じフォルダーに置いてください。初回のみ、Windowsに含まれる.NET Frameworkのコンパイラーで `.build/ClipboardCapture.exe` を作成します。2回目以降は実行ファイルを直接起動するため、PowerShellの起動とコンパイルの待ち時間がなくなります。ソース更新時は自動で再ビルドします。フォルダーへの書き込み権限が必要です。

範囲選択は前面に表示されます。表示倍率が異なるモニターや、メイン画面の左・上にあるモニターも含めて選択できます。選択画面を開いたまま再度キーを押すと、その選択画面を前面に戻します。

## Copilotキーに割り当てる

Windows、Git Bash、AutoHotkey v2が必要です。この設定はCopilotキーが `Windows + Shift + F23` を送るキーボードに対応しています。別のキー入力を送る機種では `copilot-hotkey.ahk` のキー設定を変更してください。

Git Bashでこのフォルダーを開き、次を実行します。

```bash
bash setup-copilot-key.sh
```

セットアップ時に実行ファイルをビルドするため、最初のCopilotキー入力からすぐに範囲選択が始まります。セットアップによってWindowsのスタートアップにショートカットが作成され、ログイン時に自動で有効になります。キー入力を受け取ったAutoHotkeyが選択画面を直接起動し、表示後にアクティブ化します。

別のアプリが同じキーを使用している場合は、そちらの設定を手動で解除してください。フォルダーを移動した場合は、移動先でセットアップを再実行してください。

解除するときは、スタートアップフォルダーの `ClipboardScreenshot.lnk` を削除し、通知領域のAutoHotkeyを終了します。

## 別のキーに割り当てる

1. `スクショ起動.vbs` のショートカットを作成し、デスクトップに移動します。
2. ショートカットを右クリックし、「プロパティ」を開きます。
3. 「ショートカット キー」欄をクリックして使いたいキーを押し、「OK」を押します。通常は `Ctrl + Alt + 選んだキー` になります。

ほかのアプリのショートカットと重ならない組み合わせを選んでください。

## 注意

画像ファイルは作成しませんが、Windowsのクリップボード履歴や同期を有効にしている場合は、画像が履歴や同期先に残ることがあります。

管理者権限のアプリやWindowsの保護された画面では、通常権限のホットキー・画面取得が制限される場合があります。

## 開発時の確認

Windows PowerShellで `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tests\run-tests.ps1` を実行します。ビルド後、前面表示、選択範囲の画素とサイズ、Esc、画面外へのドラッグ、負の原点を持つ複数画面サイズを確認します。テストは選択用のウィンドウを短時間表示し、クリップボードの画像をテスト画像に置き換えます。実際の複数モニター・混在DPI環境では追加の実機確認をしてください。
