【使い方】
「スクショ起動.vbs」をダブルクリックし、保存したい範囲をドラッグします。
画像はクリップボードにコピーされます。ChatGPTの入力欄で Ctrl + V を押して貼り付けてください。
Esc キーでキャンセルできます。写真ファイルは作成しません。

【キーを割り当てる】
1. このフォルダーを好きな場所に置きます。「スクショ起動.vbs」と「ClipboardCapture.ps1」は同じフォルダーに置いてください。
2. 「スクショ起動.vbs」を右クリックし、「その他のオプションを表示」→「ショートカットの作成」を選びます（Windowsの表示によっては直接「ショートカットの作成」があります）。
3. 作成されたショートカットをデスクトップに移動します。
4. ショートカットを右クリックして「プロパティ」を開き、「ショートカット キー」欄をクリックして使いたいキーを押し、「OK」を押します。通常は Ctrl + Alt + 選んだキーになります。
5. 割り当てたキーを押すと範囲選択が始まります。ほかのアプリのショートカットと重ならない組み合わせを選んでください。

※ Windowsのクリップボード履歴や、同期機能を有効にしている場合は、画像が履歴や同期先に残ることがあります。
※ スクリーンショットを撮るたびに起動するため、範囲選択が出るまで少し待つ場合があります。

【Copilotキーに割り当てる】
前提: Windows、Git Bash、AutoHotkey v2 が必要です。Copilotキーが Windows + Shift + F23 を送るキーボードに対応しています。別の入力を送る機種では copilot-hotkey.ahk のキー設定を変更してください。

1. Git Bash でこのフォルダーを開き、`bash setup-copilot-key.sh` を実行します。
2. Copilotキーを押して範囲をドラッグし、Ctrl + V で貼り付けます。

セットアップはスタートアップにショートカットを作成し、ログイン時にAutoHotkeyを起動します。別のアプリが同じキーを使っている場合は、そちらの設定を手動で解除してください。このフォルダーを移動した場合は、移動後にもう一度セットアップしてください。
解除するにはスタートアップフォルダーの「ClipboardScreenshot.lnk」を削除し、通知領域にあるAutoHotkeyを終了します。
